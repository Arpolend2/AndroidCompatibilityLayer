# AndroidCompatibilityLayer

**Порт проекта [Megler](https://github.com/Computershik73/megler-w10m) под ОС Аврора. Автор оригинального проекта — [Илья Высоцкий (Computershik73)](https://github.com/Computershik73).**

Добавляйте Android-приложения в библиотеку, настраивайте разрешения и создавайте самостоятельные RPM.

Проект экспериментальный: совместимость приложений не гарантируется. Подписи APK не проверяются, а полной изоляции Android-приложений нет — устанавливайте только доверенные файлы.

Лицензия: [GPL-3.0](LICENSE).

## Возможности

- Импорт APK, APKS и XAPK в библиотеку, в том числе через системное открытие файлов.
- При отключённом автоповороте окно Android-приложения следует ориентации, выбранной в Авроре, независимо от запроса приложения.
- Создание самостоятельных RPM для Android-приложений с выбором разрешений, отображением стадии сборки и диагностикой.
- Поддержка ARM64 и ARMv7 с выбором Android runtime и WebView по архитектуре. Запуск ARM64-приложений на ARMv7 не эмулируется; работа на ARMv7-устройстве ещё не проверена.
- [Aurora Store](https://gitlab.com/AuroraOSS/AuroraStore) внутри менеджера: установка приложений и открытие установленных самостоятельных приложений. Поддерживается перезапуск магазина.
- Опциональные настройки [microG](https://github.com/microg/GmsCore) внутри менеджера и передача общему microG метаданных запускаемого APK без проверки его подписи.
- Экспериментальная графика на Qt и GLES, мосты камеры, датчиков, Bluetooth LE, сети и звука.
- Проверка обновлений менеджера на GitHub, загрузка совместимого RPM с индикатором прогресса и предложение системной установки. Проверку при запуске можно включить отдельно.
- Обложка с приложениями и быстрыми действиями; диагностический журнал с возможностью включения, паузы и очистки записи.
- Раздел «О приложении» с описанием, ссылками и сведениями о сборке.

Aurora Store, настройки microG и самостоятельный RuStore запускались на устройстве; поддержка других приложений зависит от используемых ими Android API.

## Ограничения

- ARM64- и ARMv7-сборки включают соответствующий архитектуре Android System WebView на базе Chromium в общий runtime. Работа зависит от приложения и сайта; совместимость всех страниц и сценариев входа не гарантируется. Работа ARMv7 WebView на устройстве ещё не проверена. Этот Android WebView отличается от системного WebView Авроры, используемого для встроенной формы отчёта.
- Вход в аккаунт Google через microG подтверждён на ARM64-планшете. Это не подтверждает поддержку всех Google API или общий вход для самостоятельных приложений; межпроцессная интеграция microG остаётся экспериментальной.
- Воспроизведение AAC/H.264 находится в разработке и пока не подтверждено на устройстве; поддержку полноценного видео не заявляем.
- GPU-ускорение включено во всех сборках без дополнительных переключателей. На проверенном устройстве RuStore выводил кадры через общую GLES-текстуру, а Aurora Store передаёт живые GPU-кадры через GBM/DMA-BUF в Qt. Отдельные операции ещё используют CPU и чтение пикселей с GPU; при недоступности ускорения сохраняется резервный CPU-путь. При закрытии Store обнаружена проблема освобождения GPU-ресурсов: процесс может завершаться принудительно по таймауту.
- Мосты устройства поддерживают не все функции Android, а работа зависит от драйверов и разрешений Авроры.
- Расширенное логирование можно включить в настройках журнала. Используйте его осторожно: записи могут содержать личные данные, пути и сетевые адреса. Проверяйте журнал перед отправкой.

## Снимки камеры

Новые снимки Open Camera сохраняются сразу внутри системной папки изображений Авроры. Без явно выбранного общего `Pictures` используется отдельный каталог `Pictures/AndroidCompatibilityLayer/<package>/DCIM/OpenCamera`; весь системный `Pictures` другим APK автоматически не предоставляется. Ранее выбранный `Pictures` сохраняет свой корень.

Учитываются разрешения Android и `Pictures`/`UserDirs` Авроры. При отказе доступа запись завершается ошибкой, а не незаметным сохранением в приватный `sdcard`. `DCIM` и `Pictures/DCIM` имеют одну identity в MediaStore. Старые фотографии не переносятся; открытие снимка штатной галереей пока не реализовано.

## Сборка

Подготовьте SQLite и Android runtime по [инструкции](aurora/README.md), затем откройте корневой `CMakeLists.txt` в Aurora IDE, выберите комплект Aurora SDK для архитектуры и версии ОС устройства, соберите и установите `ru.androidcompatibilitylayer.appmanager`. Для ARMv7 необходим отдельный runtime `armeabi-v7a` и соответствующий WebView; подробнее — в [инструкции по ARM-сборке](tools/aurora/README.md). Новые самостоятельные RPM используют общий Android runtime, устанавливаемый менеджером в `/usr/share/common/ru.androidcompatibilitylayer/appmanager/android-runtime`; совместимость проверяется по маркеру ABI. Старые RPM со встроенным runtime автоматически на общий не переключаются — для перехода их нужно заново создать и установить. Изменения самого лаунчера также требуют пересоздания самостоятельного RPM.

## Использованные проекты

Предварительный список; состав и лицензии компонентов runtime ещё требуют проверки перед публикацией.

- [Megler](https://github.com/Computershik73/megler-w10m) — основа проекта; автор — Илья Высоцкий.
- [Husk](https://github.com/Leviidev/Husk) — основа части Java framework; см. [уведомление](core/framework/NOTICE).
- [Android Open Source Project](https://source.android.com/) — компоненты Android runtime, включая libcore, Conscrypt, BoringSSL, ICU и Expat.
- Android runtime также содержит компоненты [OpenJDK](https://openjdk.org/), [Apache Harmony](https://harmony.apache.org/), [Apache Xalan](https://xalan.apache.org/), [Apache HttpComponents](https://hc.apache.org/), [Bouncy Castle](https://www.bouncycastle.org/), [OkHttp](https://github.com/square/okhttp) и [Netty](https://netty.io/).
- [zlib](https://zlib.net/) и [SQLite](https://sqlite.org/) — сжатие и база данных.
- [stb_vorbis](https://github.com/nothings/stb) и [minimp3](https://github.com/lieff/minimp3) — декодирование аудио; лицензия minimp3 находится [в репозитории](aurora/audio_minimp3_LICENSE.txt).
- [Qt](https://www.qt.io/) — интерфейс и системные мосты Авроры.
- Корневые сертификаты основаны на хранилище [Mozilla](https://www.mozilla.org/) в виде набора [curl](https://curl.se/ca/cacert.pem); подробности — в `core/cacerts/README.md`.

Aurora Store и microG — отдельные проекты, которые можно установить через настройки менеджера; они не являются частью исходного кода порта. Runtime также использует файлы из образа эмулятора Android SDK. Условия их распространения и необходимые уведомления ещё проверяются; список ссылок не заменяет лицензионные уведомления.

Инструкции по сборке и подробные ограничения: [aurora/README.md](aurora/README.md). Оригинальный README Megler сохранён в [README.upstream.md](README.upstream.md).
